# Midterm Project: Titanic Survival Prediction

## Project Overview

This midterm project demonstrates the application of a complete machine learning workflow using the Titanic dataset.

The purpose of this project was to investigate passenger data, identify patterns related to survival, prepare the data for modeling, and evaluate machine learning classification models.

This project was completed as an individual machine learning investigation.

---

# Project Objectives

The objectives of this project were to:

- Apply the complete machine learning workflow
- Perform exploratory data analysis (EDA)
- Prepare and transform data for modeling
- Identify important features
- Train classification models
- Evaluate model performance
- Interpret results and limitations

---

# Dataset

## Titanic Dataset

The Titanic dataset contains information about passengers aboard the RMS Titanic.

The dataset includes information such as:

- Passenger class
- Gender
- Age
- Fare
- Family relationships
- Embarkation information
- Survival outcome

The target variable was:

**Survived**

where:

- 1 = Passenger survived
- 0 = Passenger did not survive
