## Machine Learning Types

### Supervised Learning

Supervised learning uses labeled datasets where the expected output is already known. The model learns patterns from existing examples and uses those patterns to make predictions on new data.

Examples:

* Predicting house prices
* Classifying emails as spam or not spam
* Predicting whether a patient has a specific condition

Common supervised learning algorithms include:

* Linear Regression
* Logistic Regression
* Decision Trees
* Support Vector Machines

---

### Unsupervised Learning

Unsupervised learning works with datasets that do not have labeled outputs. The goal is to discover hidden patterns, relationships, or groupings within the data.

Examples:

* Customer segmentation
* Identifying patterns in user behavior
* Grouping similar products

Common unsupervised learning algorithms include:

* K-Means Clustering
* Principal Component Analysis (PCA)
* Hierarchical Clustering

---

### Reinforcement Learning

Reinforcement learning involves an agent learning through interaction with an environment. The agent receives rewards or penalties based on its actions and improves its decisions over time.

Examples:

* Robotics
* Game-playing AI
* Autonomous vehicles

Key concepts include:

* Agent
* Environment
* Actions
* Rewards
* Learning through experience

## Machine Learning Workflow

This lab follows the typical machine learning development process:

### 1. Define the Problem

Identify the goal of the project and determine what type of machine learning problem needs to be solved.

### 2. Collect and Explore Data

Gather the dataset and examine its structure, features, and patterns.

### 3. Prepare the Data

Clean and transform the data to make it suitable for machine learning algorithms.

Common preparation steps include:

* Handling missing values
* Selecting features
* Encoding data
* Scaling numerical values

### 4. Split the Data

Divide the dataset into training and testing sets to evaluate how well the model performs on new data.

### 5. Train the Model

Apply machine learning algorithms to allow the model to learn patterns from the training data.

### 6. Evaluate Performance

Measure how well the model performs using evaluation metrics such as:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion matrix

### 7. Interpret Results

Analyze the model performance and determine whether improvements are needed.
