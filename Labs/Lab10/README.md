# Unsupervised Learning Concepts

## What Is Unsupervised Learning?

Unsupervised learning uses datasets that do not contain labeled target values. Instead, algorithms analyze the available features to discover patterns and structures.

Common applications include:

* Customer segmentation
* Market analysis
* Anomaly detection
* Recommendation systems
* Pattern recognition

The goal is not to predict a known outcome but to discover useful information hidden within the data.

---

# Clustering

## What Is Clustering?

Clustering is an unsupervised learning technique that groups similar data points together based on their characteristics.

The goal of clustering is to:

* Identify natural groupings in data.
* Discover relationships between observations.
* Understand patterns without predefined labels.

Examples:

* Grouping customers based on purchasing behavior.
* Organizing documents by topic.
* Identifying similar products.

---

## K-Means Clustering

K-Means is one of the most commonly used clustering algorithms.

The algorithm works by:

1. Selecting the number of clusters.
2. Assigning data points to the closest cluster center.
3. Updating cluster centers.
4. Repeating the process until clusters stabilize.

Advantages:

* Simple and efficient.
* Works well with large datasets.
* Easy to interpret.

Limitations:

* Requires choosing the number of clusters.
* Sensitive to outliers.
* Works best with well-separated groups.
